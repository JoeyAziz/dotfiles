# dotfiles

My personal config files.

## Contents

- `nvim/` — [LazyVim](https://www.lazyvim.org/) configuration
- `emacs/` — Emacs configuration
- `tmux/tmux.conf` — tmux configuration
- `ghostty/config` — Ghostty terminal configuration

## Install

Clone the repo and run the deploy script (symlinks everything in `MANIFEST`):

```bash
git clone https://github.com/JoeyAziz/dotfiles.git ~/dotfiles
cd ~/dotfiles
./deploy.sh MANIFEST
```
